Bu Mac mini üzerinde Vibe Radar X Safari genişletmesinin güncel main sürümünü repodan çek, kur ve çalışır hale getir. Komutları benim yerime çalıştır; yalnız gerçekten kullanıcı etkileşimi gereken Apple hesap girişi, sistem onayı veya secret girişi için bana başvur.

Repo: https://github.com/fatihdisci/heranborsacode.git

1. Önce mevcut checkout'u bul, AGENTS.md ve safari-extension/README.md dosyalarını oku. Dosya yollarını bu Mac için keşfet. Yerel değişiklikleri koru; reset --hard, clean veya zorla checkout yapma. Temiz checkout'ta main'e geçip git pull --ff-only origin main çalıştır. Repo yoksa uygun bir dizine clone et. Yerel çalışma engel oluyorsa ayrı temiz checkout kullan.
2. Node/npm, Xcode ve Safari sürümlerini kontrol et. npm ci, npm run check, npm test ve uzantı JavaScript sözdizimi kontrollerini çalıştır. Backend zaten dil seçimini destekleyecek şekilde güncellendi; sırf bu Mac'e kurulum için production deploy, migration veya secret rotasyonu yapma.
3. safari-extension/extension/ içindeki güncel manifesti ve mevcut SafariApp Xcode projesini kullan. Proje uygun değilse Apple'ın xcrun safari-web-extension-converter aracını kullan; elle pbxproj üretme. Mevcut Apple geliştirme takımı ve uygun imzalama sertifikası varsa app ve extension hedeflerini onunla derle. Apple hesabı veya sertifika yoksa kalıcı kurulumun engelini açıkla. Geçici imzasız genişletme gerekiyorsa güvenlik ayarı değişmeden önce onay iste; onay olmadan korumaları gevşetme.
4. Derlenen uygulamayı bu Mac'in Applications dizinine kur ve aç. Safari > Ayarlar > Genişletmeler bölümünden Vibe Radar X'i etkinleştir. Yalnız gerekli x.com/twitter.com ve manifestteki backend adresleri için izin ver; sistem onayı gerekiyorsa kullanıcıya tamamlat.
5. Mevcut SAFARI_EXTENSION_TOKEN bu Mac'te güvenli biçimde kayıtlıysa onu koru. Yoksa kullanıcının AYNI token'ı genişletmenin ayarlarındaki parola alanına veya yerel dosya içe aktarma seçeneğine girmesini sağla. Token'ı sohbette isteme, ekranda/logda gösterme, source/manifest/git içine yazma. Cloudflare mevcut secret değerini geri vermez; yeni token üretip mevcut production token'ını değiştirme. OPENAI_API_KEY yalnız Cloudflare'da kalacak.
6. Safari'de x.com açıp uçtan uca doğrula: ✦ butonu tek kez görünüyor mu; Yanıt ve Alıntı çalışıyor mu; Dil menüsünde Otomatik, Türkçe (TR), İngilizce (ENG) var mı? İngilizce tweet + Otomatik -> İngilizce; Türkçe tweet + Otomatik -> Türkçe; İngilizce tweet + TR -> Türkçe; Türkçe tweet + ENG -> İngilizce. Türkçe bir notun Otomatik moddaki İngilizce kaynak dilini değiştirmediğini de kontrol et. Metinler doğal olsun, kişisel deneyim uydurulmasın.
7. Bir yanıtı ve bir alıntıyı X editörüne yerleştirip doğru kaynak tweet ve tek kopya taslak olduğunu kontrol et. ASLA Gönder/Post düğmesine basma; hiçbir gönderi yayınlama. Test taslaklarını göndermeden kapat.
8. Sonuçta kurulu git commit'ini, uygulama yolunu, test sonuçlarını, kalıcı/geçici kurulum durumunu ve varsa yalnız gerçekten kullanıcıya kalan engeli kısaca bildir. Başarılı olduğunu ancak arayüzde çalıştığını gördükten sonra söyle.
